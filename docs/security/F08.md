# Self security review: F08 control API and data services

Date: 2026-11-15. Self review (not independent).

- Grants: HMAC-SHA-256 over the exact encoded claims; secrets ≥ 32 chars; constant-time `crypto.subtle.verify`; claims re-validated after signature; ≤ 24 h lifetime; audience bound. Grants are bearer tokens: hosts must send them only over TLS and keep lifetimes short. No revocation list yet (N13 owns cross-service revocation).
- Tenant isolation: tenant comes only from the grant; every store query is keyed by tenant+project; tests cover cross-tenant reads, claims and project scoping.
- Input bounds: documents 1 MiB, objects 16 MiB, job inputs 64 KiB, ids/keys regex-restricted (no `..`).
- Objects are returned with `content-disposition: attachment` and `nosniff`; integrity re-checked on read.
- SQL: parameterized only; the engine package has no driver and receives a least-privilege client from the host. Server-readable data is not end-to-end encrypted and is not claimed to be.
- CI integration workflow has empty default permissions, no secrets, pinned actions and a CI-only database password.

No blocking finding.
