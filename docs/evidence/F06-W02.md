# F06/F07 provisional foundation, W01 world schema, W02 runtime lifecycle and the example world

Date: 2026-11-15. Recorded by an assistant session acting under the owner's delegated work brief. **Self-reported local evidence; no independent review. Nothing here is accepted or verified, and no physical headset was used.**

## What was implemented

- **F06 (provisional, owner-deferred):** [decision 0002](../decisions/0002-provisional-foundation-selection.md) selects Babylon.js 9.30.0 + Rapier 0.21.0 on the existing F04/F05 comparison evidence. [`capability-map.json`](../foundation/capability-map.json) assigns all 170 remaining cards (103 implement, 19 adapt, 7 reuse, 41 application-owned). `scripts/check-foundation.mjs` validates the map against the full plan and dependency graph and rejects any engine card mapped onto the retired Hubs/Spoke path.
- **F07:** [`upstream-pins.json`](../foundation/upstream-pins.json) records exact versions, sha512 integrity, license, role and update owner; the check verifies each pin against the lockfile it names and requires every workspace dependency to be exact and recorded. No fork is needed.
- **W01:** `@browser-vr-engine/world` — versioned world/entity/prefab/asset-reference schema, bounded validation, nested-prefab expansion with stable composite ids, canonical serialization, version-0 migration.
- **W02:** `@browser-vr-engine/runtime` — create/load/start/suspend/resume/unload/dispose lifecycle around an injectable `RendererPort`, cancellation of superseded loads (late results are unmounted, never published), single frame loop, visibility suspension, and local asset/authorization/persistence/transport services that grant only explicit local capabilities. Also a W04 keyboard `ActionState` subset.
- **Example world:** `examples/world-demo` — Babylon.js `RendererPort` adapter (right-handed, Y-up, meters), two original worlds (courtyard, gallery), desktop WASD/mouse/touch look with collisions and gravity, WebXR `immersive-vr` entry via Babylon's default experience when a device is reported, opt-in WebAudio spatial tones attached to moving entities, and static docs pages.
